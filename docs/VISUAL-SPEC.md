# LyricLab — the visual spec, one line per screen

Written 2026-09-01 against the 14-screen map captured from the running build.
Ruled 🏆 LEGENDARY the same day: **UI and identity art is game functionality, not
frozen art.** The freeze covers the cast/court 3D pipeline only.

**The test for every row: does a player look at this every session?**

⚠️ Nothing here is approved. Each row is ruled individually before any CU is spent.
Reference classes are graded **READ** — recalled product patterns, not measurements.

## What the table says when you read it as a budget

⛔ **Rows 1, 2 and 3 are one commission and they cover the three most-looked-at
elements in the game.** Rows 9 and 10 then reuse them for free.

🔑 **Row 11 is not an art item at all — `class-intro` rendered blank.** It is the
one defect the capture found, and it costs nothing to fix.

⚠️ **Row 13 is the honest one: the old main menu is now redundant**, and drawing
art for a screen that should be deleted is the exact failure this project has
already paid for.
